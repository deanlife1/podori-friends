포돌이와 친구들

끝없이 이어지는 산과 숲을 걸어 다니는 브라우저 오픈월드. 무료 도구만으로 HTML 파일 하나에 담았습니다.

이렇게 만들었어요
  • 지형: 심플렉스 노이즈를 겹쳐 만든 절차 생성 높이 함수
  • 넓은 맵: 128m 청크를 주변 15×15칸만 만들고 멀어지면 지움
  • 지형 재질: 경사·높이로 풀·흙·바위 결·눈·모래를 픽셀마다 섞고 요철을 더함
  • 나무: 캔버스에 그린 잎 텍스처를 붙인 카드 수십 장, 바람에 흔들림
  • 나무·바위 배치: 청크마다 인스턴싱, 먼 청크는 단순 모델(LOD)
  • 풀: 플레이어 주변 3만 포기를 따라다니며 바람에 흔들림
  • 빛: 대기 산란 하늘 셰이더를 반사광으로도 사용, 그림자·안개·흐르는 구름
  • 후처리: 안티앨리어싱, 빛 번짐, 색보정, 비네팅, 필름 그레인
  • 곰둥이·포돌이·토실이·란오리: 참고 그림 → Hunyuan3D(무료)로 모양 생성 → 그림을 앞·뒤·옆에서 투영해 텍스처 베이크 → 블렌더 스크립트로 뼈대 자동 삽입
  • 털: 뼈대를 공유하는 껍질 10겹을 법선 방향으로 띄워 겹쳐 그리는 셸 퍼, 끝이 바람에 눕는다
  • 동작: 뒤뚱걸음·깡충뛰기·종종걸음·점프·비행·손 흔들기·꼬리 살랑을 뼈 회전으로 코드에서 계산
  • 도구: Three.js r160, Blender 5.2, Hunyuan3D 2 (모두 무료)
