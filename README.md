# 포돌이와 친구들

끝없이 이어지는 산과 숲을 곰둥이·포돌이·토실이·란오리가 함께 걸어 다니는 브라우저 오픈월드 데모. 무료 도구만 썼습니다.

- 지형·숲·하늘·물: Three.js로 절차 생성 (청크 스트리밍, LOD, 인스턴싱)
- 캐릭터: 참고 그림 → Hunyuan3D(허깅페이스, 무료)로 모양 생성 → 그림을 앞·뒤·옆에서 투영해 텍스처 베이크 → Blender 스크립트로 뼈대 자동 삽입 (`refs/blender_rig.py`)
- 조작: WASD 이동, Shift 달리기, Space 점프, F 비행, V 시점 전환

파일 하나(`index.html`)와 모델 네 개(`models/`)로 동작합니다.
